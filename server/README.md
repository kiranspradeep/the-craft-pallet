# The Craft Pallet — Backend API

Production-grade REST API for The Craft Pallet personalized gifts platform.

## Tech Stack

- **Runtime**: Node.js
- **Framework**: Express 5
- **Language**: TypeScript
- **Database**: PostgreSQL
- **ORM**: Prisma
- **Auth**: JWT + bcrypt
- **Validation**: Zod
- **File Processing**: Sharp, AdmZip, Multer
- **Logging**: Winston
